| 날짜 | 내용 |

## 1. 목적
평택시 사립작은도서관 운영자가 보탬e에 집행내역을 등록할 때, **집행 1건의 증빙서류(사진·PDF)를 정해진 순서대로 PDF 한 파일로 합치는** 웹 도구.
- 집행 유형(세목)을 고르면 필요한 서류 목록이 칸으로 나오고, 칸마다 파일을 넣으면 순서대로 합쳐진다.
- 필수서류 칸이 비어 있으면 저장 전에 한 번 확인시킨다(막지는 않는다).
- 서류 목록이 필요 없을 때는 **파일만 합치기**로 넣은 순서대로 바로 묶는다.

## 2. 사용자와 환경
- 사용자: 작은도서관 운영자(60대 포함, 컴퓨터 비전문가). 설치·회원가입 없이 **주소만 열면 바로 사용**.
- 기기: 주로 Windows PC(크롬·엣지·웨일). 스마트폰(안드로이드·아이폰)에서도 사용 가능해야 함(사진을 폰으로 찍는 경우가 많음).
- 언어: 한국어만.

## 3. 배포·기술 조건
- **GitHub 저장소 + GitHub Pages**로 배포하는 정적 웹페이지(HTML/CSS/JS). 서버·데이터베이스·빌드 과정 없음.
- **모든 처리는 사용자 브라우저 안에서만** 한다. 파일을 어디에도 업로드하지 않는다(강사 신분증·통장사본 등 개인정보가 들어감). 화면 위에 "넣은 서류는 인터넷에 올라가지 않고, 이 화면에서 바로 합쳐집니다." 문구 표시.
- 외부 서비스·분석 도구(구글 애널리틱스 등) 넣지 않는다.
- 라이브러리는 jsDelivr CDN에서 버전을 고정해 불러온다: `pdf-lib@1.17.1`(합치기), `pdfjs-dist@3.11.174`(PDF 미리보기), `heic2any@0.0.4`(아이폰 사진 변환, HEIC를 넣을 때만), 글꼴 `pretendard@1.3.9`.
- 유형별 서류 목록은 **별도 설정 파일(JSON)**로 분리해서, 코드를 몰라도 매년 매뉴얼이 바뀌면 그 파일만 고칠 수 있게 한다. 어느 해 파일을 쓸지는 `index.html`의 `data-config` 한 곳에서 정한다.

## 4. 화면 흐름 (단계형)
상단에 진행 단계(1 사업 → 2 유형 → 3 정보 → 4 서류 → 5 저장)를 가는 선과 단계 이름으로 표시하고, 그 위에 "2 / 5단계 · 집행 유형 고르기"처럼 지금 위치를 문장으로 쓴다. 지난 단계는 눌러서 돌아갈 수 있다.

### 1단계: 사업 선택
- 첫 화면에 "사용 방법" 3줄 안내와 [처음 쓰는 분 보기] 도움말.
- 작은도서관 우수도서관 육성 / 독서환경 조성 / 독서문화프로그램 지원 / 아이돌봄 독서문화프로그램 / 냉난방비 지원 카드. 카드 위 탭에 "집행 유형 N가지".
- 사업에 따라 고를 수 있는 유형만 다음 단계에 보이게 한다(6절 표의 '사업' 열).
- 카드 아래에 **[서류 목록 없이 파일만 합치기]** 상자. 누르면 2·3단계를 건너뛰고 4단계(칸 하나 "합칠 파일")로 간다. 이미 정리해 둔 PDF를 묶거나 목록에 맞는 유형이 없을 때 쓴다.

### 2단계: 집행 유형(세목) 선택
- 카드형 버튼. 카드 위 서류철 탭에 보탬e **보조세목**(예: 행사운영비), 카드 안에 유형 이름·짧은 주의사항·"고르기 →".
- 고른 카드는 초록 테두리 + "✓ 고른 유형".

### 3단계: 집행 정보 입력 (선택)
- 집행일, 금액(원), 거래처 또는 내용 — 파일 이름 자동 생성에만 사용. 모두 비워도 진행 가능.

### 4단계: 서류 넣기 (핵심 화면)
- 화면 위 안내 두 가지:
  - **필수란?** "보탬e 정산에 꼭 있어야 하는 서류라는 뜻이에요. 칸이 비어 있어도 PDF는 만들어집니다. 여러 서류를 이미 하나로 합친 PDF는 첫 서류 칸에 넣고 나머지 칸은 비워 두세요. 이름이 딱 맞지 않아도 같은 역할의 서류(예: 카드전표 대신 이체확인증)는 그 칸에, 애매한 서류는 맨 아래 기타 서류에 넣으면 됩니다."
  - **알림:** 고른 유형의 주의사항(설정 파일의 `tip`).
- 선택한 유형의 서류 목록이 **순서대로 칸**으로 나열됨. 각 칸에 [필수] / [해당 시] 표시와 짧은 도움말.
- 칸마다 파일 끌어다 놓기 또는 [파일 고르기]. 휴대폰에서는 [사진 찍기]도 보인다.
- 한 칸에 여러 파일 가능(예: 강의확인서 4회분). 칸 사이로 끌어 옮기기도 가능.
- 넣은 파일은 썸네일로 표시, 각 장 아래 **[◀ 앞으로] [뒤로 ▶] [↻ 돌리기] [빼기]** 글자 버튼(기호만 쓰지 않음).
- 칸 상태: 비었음(흰 칸) / 넣었음(초록 ✓, "2쪽 넣음") / 저장 단계를 거친 뒤 비어 있는 필수 칸(노란 칸, "?", "비어 있어요. 다른 파일에 함께 들어 있거나 비슷한 서류로 냈다면 그대로 두셔도 됩니다.").
- 맨 아래 [기타 서류] 칸: "어느 칸에 넣을지 애매한 서류는 여기에".
- 아래 고정 막대: 넣은 쪽수, 예상 용량, (해당 시) "용량이 커서 파일 2개로 나눠 저장됩니다".

### 5단계: 확인 및 저장
- 서류 목록 요약: 넣음 ✓ n쪽 / 빈 필수 칸 "? 비어 있음 · 확인"(노란 줄) / 빈 해당 시 칸 "–".
- 파일 이름(자동, 수정 가능).
- [PDF로 저장하기] → 빈 필수 칸이 있으면 확인창: "아래 필수 칸이 비어 있어요. · ○○ · ○○ … 다른 파일에 함께 들어 있거나 비슷한 서류로 냈다면 그대로 저장하셔도 됩니다. 이대로 저장할까요?"
- 저장 후 안내: "보탬e 첨부란에 이 파일 하나만 올려 주세요(기본서류/증빙서류 칸 구분 없이 한 곳에)." 2개로 나뉜 경우 "이 파일 2개를 모두 올려 주세요" + [2번 파일 내려받기] 버튼.
- [새 집행 시작] 버튼(같은 사업·유형 유지 옵션, 기본 켬).

## 5. PDF 생성 규칙
- 순서: 서류 목록 순서 → 칸 안에서는 사용자가 정한 순서.
- 지원 파일: JPG, PNG, HEIC(아이폰), PDF(여러 쪽이면 전체 포함). 그 외(HWP, 엑셀 등)는 "PDF로 저장한 뒤 넣어 주세요" 안내. 암호 걸린 PDF는 암호를 풀고 넣으라고 안내.
- 이미지는 A4 한 장에 비율 유지해서 맞춤(여백 18pt). **가로 사진은 A4 가로 페이지**에 넣는다. 세로 페이지로 넣고 싶으면 4단계에서 [돌리기](돌린 결과가 세로면 A4 세로). 저장 화면의 가로/세로 선택지는 두지 않는다. 휴대폰 사진 방향(EXIF) 자동 보정.
- 용량: 사진은 긴 변 2000px·JPEG 품질 0.8로 자동 압축. 저장 전 예상 용량 표시.
- **보탬e 첨부 한도 파일당 100MB.** 넘으면 최대 2개 파일로 나눠 저장한다(서류 칸 경계에서 우선 나눔). 그래도 넘치면 사진을 더 줄여(긴 변 1400px) 다시 시도하고, 그래도 안 되면 "사진 수를 줄이거나 집행 건을 나눠 주세요" 안내. 한도·최대 파일 수는 설정 파일에서 바꾼다.
- 파일 이름 자동: `집행일_유형_거래처_금액.pdf` (예: `20261028_강사료_재봉틀수업_364800.pdf`). 입력이 없으면 `유형_저장일시.pdf`, 파일만 합치기는 `파일합치기_저장일시.pdf`. 나뉘면 `_1`, `_2`. 저장 전에 이름 수정 가능.
- 표지·구분 페이지는 넣지 않는다(실제 증빙만).

## 7. 화면·사용성
- 디자인 기준: Claude 디자인 시스템 "작은도서관 증빙도구"(서류철 테마). 넓은 면은 흰색, 상태에만 색을 쓴다.
  - 도서관 초록: 주 버튼, 지금 단계, 넣은 서류, 머리 위 띠
  - 서류철 노랑: 보조세목 탭, 끌어 올림, 비어 있는 필수 칸(확인)
  - 인주 빨강: '필수' 표시, 넣을 수 없는 파일 같은 문제
- 글꼴 Pretendard. 기본 17px, 제목 28px, 가장 작은 글자 15px(탭·칩 13px). 굵기는 제목 600, 버튼·이름 500, 나머지 400. (처음 18px 이상·굵은 디자인은 부담스럽다는 의견으로 조정)
- 누르는 것은 44px 이상, 일반 버튼 52px, 저장 버튼 60px. 선은 1px, 그림자 없음.
- 이모지 쓰지 않는다. 기호는 반드시 글자와 함께.
- 말투: 존댓말, 쉬운 말(넣기·빼기·내려받기). 오류는 무엇이 안 됐는지 + 무엇을 하면 되는지.
- 모바일 대응(세로 화면에서 카드·칸 한 줄씩, 옆으로 넘치지 않음). 어두운 화면 설정 지원.
- 하단에 "평택시립 안중도서관 작은도서관 담당 / 문의 031-8024-8333"(설정 파일).
- 새로고침·창 닫기 시 넣은 파일이 사라진다는 경고.

## 8. 하지 않을 것
