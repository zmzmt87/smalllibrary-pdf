## 만든 것
- 5단계 화면: 사업 → 집행 유형 → 집행 정보(선택) → 서류 넣기 → 확인·저장
- 서류 칸마다 사진(JPG·PNG·아이폰 HEIC)·PDF 넣기, 끌어다 놓기, 휴대폰 [사진 찍기]
- 넣은 장마다 [◀ 앞으로] [뒤로 ▶] [↻ 돌리기] [빼기], 칸 사이 끌어 옮기기
- PDF 합치기: 서류 순서대로, 사진은 A4에 맞춤·방향 자동 보정·자동 압축
- 파일 이름 자동(`집행일_유형_거래처_금액.pdf`), 저장 전 수정 가능
- 용량 한도(파일당 100MB)를 넘으면 최대 2개 파일로 나눠 저장(서류 칸 경계에서 우선 나눔)
- **서류 목록 없이 파일만 합치기** 모드(첫 화면 아래)
- 모든 처리는 브라우저 안에서만, 파일 전송 없음 / 새로고침 경고
- 디자인: 서류철 테마(초록·노랑·빨강), 글꼴 Pretendard, 어두운 화면 지원

## 서류 목록: 2026 매뉴얼 대조 후 바뀐 점
- 냉난방비: **전기료·가스료**(사용량 고지서, 계산식은 해당 시) + **유류비** 신설(보조세목: 공공요금 및 제세). 두 유형은 서류가 달라 따로 둠
- 홍보배너·현판 제작: 매뉴얼에는 있으나 거의 쓰지 않아 **넣지 않기로 결정**
- 독서문화프로그램: 봉사자 실비·홍보물 추가
- 아이돌봄: 재료비 제외, 간식비(아이돌봄) 따로(강의확인서 불필요)
- 강사료: 서류 순서 매뉴얼대로, '이체확인증' → '이체영수증'
- 재료비: 거래명세서는 '해당 시'(카드전표로 확인되면 생략)
- '사무·도서관리용품' → '도서관리용품', '비품 수선' → '비품 운영·수선비'
- 매뉴얼에 없지만 남겨 둔 것: 이체수수료, 강사카드(해당 시) — 유지 여부 확인 필요
