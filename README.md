# 작은도서관 보조금 증빙 PDF 합치기

평택시 사립작은도서관 운영자가 보탬e에 집행내역을 등록할 때,
**집행 1건의 증빙서류(사진·PDF)를 정해진 순서대로 PDF 한 파일로 합쳐 주는** 웹 도구입니다.

- 설치·회원가입 없이 주소만 열면 됩니다.
- 넣은 파일은 **인터넷으로 보내지지 않고** 내 컴퓨터(휴대폰) 브라우저 안에서만 처리됩니다.

---

## ① 사용 주소

```
https://<GitHub계정이름>.github.io/smalllibrary-pdf/
```

크롬·엣지·웨일(PC), 휴대폰 크롬·사파리에서 쓸 수 있습니다.

**사용 순서**: 사업 고르기 → 집행 유형 고르기 → (집행일·금액·거래처 적기, 생략 가능) → 서류 칸마다 파일 넣기 → [PDF로 저장] → 받은 파일 하나를 보탬e에 올리기

## ② GitHub Pages 켜는 방법 (처음 한 번)

1. GitHub에 로그인하고 오른쪽 위 **+** → **New repository**.
2. Repository name에 `smalllibrary-pdf` 입력, **Public** 선택 → **Create repository**.
3. **uploading an existing file** 링크를 눌러 이 폴더의 파일을 모두 끌어다 놓습니다.
   (`index.html`, `app.js`, `style.css`, `README.md`, `config` 폴더)
   → 아래 **Commit changes**.
4. 저장소 위쪽 **Settings** → 왼쪽 **Pages**.
5. Source: **Deploy from a branch**, Branch: **main** / **/(root)** → **Save**.
6. 1~2분 뒤 같은 화면 위쪽에 사용 주소가 나타납니다.

> 파일을 더블클릭해서 열면 서류 목록을 못 불러옵니다. 꼭 위 주소(https://…)로 여세요.

## ③ 매년 서류 목록 고치는 방법

서류 목록은 **`config/docs-2026.json`** 파일 하나에 들어 있습니다. 코드를 몰라도 이 파일만 고치면 됩니다.

### GitHub에서 바로 고치기
1. 저장소에서 `config` → `docs-2026.json` 클릭 → 오른쪽 위 연필(✏) 아이콘.
2. 글자를 고친 뒤 **Commit changes**.
3. 1~2분 뒤 사용 주소를 새로고침하면 반영됩니다.

### 자주 고치는 곳

| 하고 싶은 것 | 고칠 곳 |
|---|---|
| 문의 전화번호 | `"contact"` 의 `"phone": "031-8024-8333"` |
| 보탬e 첨부 용량 한도(파일 1개당 MB) | `"maxFileSizeMB": 100` |
| 한도를 넘을 때 나눌 최대 파일 수 | `"maxFiles": 2` |
| 서류 이름 바꾸기 | 해당 유형 `"docs"` 안의 `"name": "…"` |
| 필수 ↔ 해당 시 바꾸기 | `"required": true` (필수) / `false` (해당 시) |
| 칸 옆 도움말 | `"tip": "…"` (없으면 빼도 됨) |
| 서류 순서 바꾸기 | `docs` 안에서 `{ … }` 줄의 순서를 바꿈 |
| 보탬e 보조세목 | `"budgetItem": "…"` |
| 어느 사업에서 보일지 | `"programs": ["우수", "독서문화", "아이돌봄"]` |

### 서류 하나 추가하는 예
`강사료`의 `docs` 목록에서 원하는 위치에 한 줄을 넣습니다.

```json
{ "name": "출강확인서", "required": true, "tip": "강사 서명이 있어야 합니다" },
```

### 꼭 지킬 것 (틀리면 화면에 오류 안내가 뜹니다)
- 글자는 **큰따옴표 `"`** 로 감쌉니다.
- 줄과 줄 사이에는 **쉼표 `,`** 를 넣고, 목록의 **마지막 항목 뒤에는 쉼표를 넣지 않습니다.**
- `true` / `false` 에는 따옴표를 붙이지 않습니다.

### 새해(예: 2027년)로 바꿀 때
1. `docs-2026.json` 을 열어 내용을 복사하고, `config` 폴더에 **Add file → Create new file** 로 `docs-2027.json` 을 만들어 붙여 넣은 뒤 고칩니다.
2. `index.html` 을 열어 `data-config="config/docs-2026.json"` 의 `2026` 을 `2027` 로 바꿉니다.

### 참고 (관리자용)
- 빌드 과정 없는 정적 페이지입니다: `index.html`, `app.js`, `style.css`, `config/docs-YYYY.json`.
- 사용 라이브러리(jsDelivr CDN, 버전 고정): `pdf-lib@1.17.1`(합치기), `pdfjs-dist@3.11.174`(PDF 미리보기), `heic2any@0.0.4`(아이폰 사진 변환, HEIC를 넣을 때만 불러옴).
  CDN 대신 저장소에 넣고 싶으면 위 파일들을 `lib/` 폴더에 내려받고 `index.html`·`app.js` 의 주소를 `lib/…` 로 바꾸면 됩니다.
- 분석 도구·서버·저장소(localStorage 등) 사용 없음. 넣은 파일은 새로고침하면 사라집니다.
- 사진은 긴 변 2000px·JPEG 품질 0.8로 줄여서 넣습니다(`config` 의 `"image"` 에서 조정).
- 합친 PDF가 한도(`maxFileSizeMB`)를 넘으면, 서류 칸 경계에서 우선 나눠 최대 `maxFiles`개 파일로 저장합니다. 그래도 넘치면 사진을 더 줄여(긴 변 1400px) 다시 시도하고, 그래도 안 되면 사진 수를 줄이라고 안내합니다.
